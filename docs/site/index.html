ShiftPV

A Kubernetes CSI driver for node-local RWO filesystem volumes, with planned cold moves between recoverable nodes.

ShiftPV uses directories on existing filesystems. Backups, replication and recovery from permanent node or disk loss remain the operator's responsibility.
